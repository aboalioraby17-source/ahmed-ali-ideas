# Ahmed Ali — مساحة الأفكار

موقع تعريفي بواجهة فقط، عربي ومتجاوب مع الهاتف والكمبيوتر.

## الملفات
- `index.html` — محتوى الموقع.
- `style.css` — التصميم والألوان والحركات.
- `script.js` — قائمة الهاتف، تبديل المظهر، وتأثيرات الظهور.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `ahmed_personal_website`.
3. افتح `index.html` في المتصفح.

لا يحتاج الموقع إلى تثبيت أي مكتبات. الخط يتم تحميله من Google Fonts عند توفر الإنترنت.

## التعديلات السريعة
- الاسم: ابحث عن `Ahmed Ali` في `index.html`.
- البريد: ابحث عن `hello@example.com` في `index.html` و`script.js`، واستبدله ببريدك.
- نصوص المشاريع: عدّل عناوين ووصف البطاقات في `index.html`.
- الألوان: عدّل المتغيرات الموجودة في بداية `style.css`.

المشاريع المعروضة خيالية/تجريبية، ولا تمثل أعمالًا حقيقية.
